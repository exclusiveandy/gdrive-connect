Automation project

Drive File Converter

A simple automation that converts files from a designated Google Drive source folder into a requested format and saves the converted files to a designated Google Drive destination folder.

Project overview

Drive File Converter is designed to reduce repetitive file-conversion work. A GitHub Actions workflow runs the conversion process, retrieves the files selected for processing from Google Drive, converts them according to the configured rules, and places the resulting files in a separate destination folder in Google Drive.

The project is intended for personal or authorized business workflows. It does not provide a public file-hosting service or make users' Drive files publicly accessible.

How it works

1Read source files

The workflow accesses files in the configured Google Drive source folder.

2Convert files

The workflow processes each eligible file and converts it to the configured output format.

3Save results

Converted files are uploaded to the configured Google Drive destination folder.

Google Drive access

When Google authorization is enabled, the application requests only the Google Drive permissions needed for its configured workflow. Files are accessed to perform the requested conversion and save the resulting output. The application should not request broader Drive access than the workflow requires.

Use and support

This project is provided for its configured automation purpose. For questions about the project or its handling of Google user data, contact the project owner using the support contact published with this application.

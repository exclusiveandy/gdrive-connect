Project overview

Drive File Converter reduces repetitive file-conversion work. Files you upload are processed by a GitHub Actions workflow, using a designated Google Drive folder as temporary working storage, and the converted result is returned to you on this page.

The project is intended for personal or authorized use. Files are used only to perform the conversion you request. This site does not make anyone's Google Drive files publicly accessible.

Google Drive access

The application requests only the Google Drive permissions needed for its configured workflow: reading files placed in its source folder and saving converted output to its destination folder. It does not request broader access than the workflow requires.

Use and support

This project is provided for its configured automation purpose. For questions about the project or its handling of Google user data, contact the project owner using the support contact published with this application.
